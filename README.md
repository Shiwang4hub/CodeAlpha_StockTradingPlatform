# Stock Trading Platform

A Java console-based stock trading simulation developed as part of the CodeAlpha Java Programming Internship.

## Project Overview

The Stock Trading Platform simulates basic stock market operations. Users can view available stocks, buy and sell shares, manage their portfolio, check their balance, and view transaction history.

## Features

- View available market stocks
- Buy stocks
- Sell stocks
- Portfolio management
- Calculate total portfolio value
- Check available balance
- View transaction history
- Input validation
- Object-Oriented Programming (OOP)

## Technologies Used

- Java
- ArrayList
- Classes and Objects
- Encapsulation
- Loops
- Conditional Statements
- Scanner

## Classes Used

### Stock
Stores stock symbol, company name, and current price.

### User
Manages user balance, stock portfolio, buying and selling operations.

### Transaction
Stores and displays buy/sell transaction details.

## How to Run

1. Download `StockTradingPlatform.java`.
2. Open it in a Java-supported IDE or online Java compiler.
3. Compile and run the program.
4. Enter your name and initial balance.
5. Use the menu to view stocks, buy/sell shares, and manage your portfolio.
